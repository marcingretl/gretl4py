version 0.22:
    - add interface to 'summary'
    - make gretl.get_data() more functional
    - add time-series filters: Hodrick-Prescott, Baxter-King, and Butterworth
    - add 'include' as an interface for loading user-contributed packages
    - add 'frompkg' option for loading datasets
    - initial access to user-defined variables (gretl specific)
    - support for Windows on ARM64
    - use LLVM/Clang 20.x as default compiler
    - basic tweaks for pybind11 3.x
    - GretlBundle class: an interface to libgretl's bundle

version 0.21:
    - 'lagselect' switched off for VAR due to SIGSEGV
    - OpenBLAS 0.3.30 for linux packages
    - corrgm added as test (both: data-based and model-based)
    - eliminate any JSON-based data exchange

version 0.2:
Massive changes:
    - The code was refactored (C++17 required)
    - New estimators: hsk, midasreg, quantreg, tobit, var, vecm
    - Dataset handling reworked:
        - Introduced _gretl.Dataset class
        - get_data() is now the sole entry point for loading datasets
        - Added methods for filtering, testing, data access, and more
    - Model handling redesigned:
        - Introduced _gretl.Model base class with derived types
        - Model instances are now created on the C++ side
        - New methods for forecasting, testing, access, and diagnostics
    - Packaging:
        - Now distributed as .whl (wheel) files

    - Initial release
