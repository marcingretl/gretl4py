\section{Introduction}\label{sec:introduction}
The \gretlpy package is a software collection that
provides an interface to \lgretl \citep{gretl_manual}
for the \python{3.xx} (3.11 and 3.12 were tested)
language and consists of the following elements:
\begin{itemize}
	\item binary bindings written in \cpp (see Section~\ref{sec:binary_bindings}),
	\item a \texttt{Model} class implemented in \python (see Section~\error{XXX}),
	\item a set of utility functions implemented in \python (see Section~\error{XXX}).
\end{itemize}
To run, the package needs to be installed in the \python
module search path, along with the following \python packages:
\texttt{sys}, \texttt{site}, \texttt{os}, \texttt{numpy},
\texttt{pandas}, \texttt{json}, \texttt{csv}, and \texttt{subprocess}.
