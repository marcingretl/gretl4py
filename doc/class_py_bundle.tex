\subsection[gretl.Bundle class]{\classpybundle}\label{sec:classpybundle}
A \gretlcmd{bundle} is a container or wrapper for various
sorts of objects---primarily scalars, matrices, strings, arrays
and bundles. (Yes, a \gretlcmd{bundle} can contain other bundles).\newline
Secondarily, series and lists can be placed in bundles as well,
but with some caveats. (Please refer to \cite{gretl_manual}.)
A \gretlcmd{bundle} takes the form of a hash table or associative
array: each item placed in the \gretlcmd{bundle} is associated
with a key which can used to retrieve it subsequently.


\subsubsection{\classpybundleb constructors}
The \classpybundle provides the following constructors:

\gretlfpycmd{Bundle()}
\estdesc{Default constructor.}
\begin{lstlisting}[style=pythonstylefoot]
~gretl.Bundle -> gretl.Bundle
\end{lstlisting}

\gretlfpycmd{Bundle()}
\estdesc{On-the-fly constructor.}
\begin{lstlisting}[style=pythonstylefoot]
~gretl.Bundle(**kwargs) -> gretl.Bundle
\end{lstlisting}
\maptof{\_(**kwargs)}{bundle}
Example:\newline
\pythcodef{b = ~gretl.Bundle(x=10, name="foo", mat=numpy.array([[1,2],[3,4]]))}
\generaldesc{Construct a \gretlcmd{bundle} optionally initialized
	with keyword arguments. Each keyword becomes a key in the
	\gretlcmd{bundle}, with its value stored according to type
	(\pythcode{bool}, \pythcode{int}, \pythcode{float}, \pythcode{str},
	\pythcode{numpy.ndarray}, \pythcode{gretl.Matrix} or another \pythcode{gretl.Bundle}).}


\subsubsection{\classpybundleb operators}
The \classpybundle class provides the following operators:

\gretlfpycmd{[]}
\estdesc{Operator for accessing, assigning, or deleting a
	\pythcode{gretl.Bundle} element stored under a given \textit{key}.}
\begin{lstlisting}[style=pythonstylefoot]
b[key] -> object
b[key] = object
del b[key]
\end{lstlisting}
\generaldesc{This operator retrieves, assigns, or deletes the
	\pythcode{object} associated with \textit{key} in a
	\pythcode{gretl.Bundle}. The \pythcode{object} may be one of
	the following types:
	\pythcode{bool}, \pythcode{int}, \pythcode{float},
	\pythcode{str}, \pythcode{numpy.ndarray},
	\pythcode{gretl.Matrix}, or another \pythcode{gretl.Bundle}.}


\subsubsection{\classpybundleb public methods}
The \classpybundle class provides the following public methods:

\gretlfpycmd{keys()}
\estdesc{Returns the names of all elements stored in the bundle.}
\begin{lstlisting}[style=pythonstylefoot]
.keys() -> list
\end{lstlisting}
\maptof{getkeys(b)}{strings}
\generaldesc{If the bundle is empty, an empty list is returned.}

\gretlfpycmd{pop()}
\estdesc{Removes and returns the data item stored under \textit{key},
	if such an item is present.}
\begin{lstlisting}[style=pythonstylefoot]
.pop(key: str) -> object
\end{lstlisting}

\gretlfpycmd{print()}\label{met:gretlbundle::print}
\estdesc{Prints the contents of the \gretlcmd{bundle} in \gretl-style.}
\begin{lstlisting}[style=pythonstylefoot]
.print(tree: bool = False)
\end{lstlisting}
\mapto[none]{print ~bundle~}
\mapto[none]{print ~bundle~ --tree}
\generaldesc{If \pythcode{tree=True}, the contents of nested bundles
	are also listed. Otherwise only the top-level members of the bundle
	are listed.}

\gretlfpycmd{to\_dict()}
\estdesc{Converts the \gretlcmd{bundle} to a \python{} \pythcode{dict}.}
\begin{lstlisting}[style=pythonstylefoot]
.to_dict() -> dict
\end{lstlisting}
\generaldesc{Nested \pythcode{gretl.Bundle} objects are recursively
	converted to \pythcode{dict} objects.}
