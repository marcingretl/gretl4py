\section{Bayesian Econometrics}
This section provides an overview of Bayesian
econometric methods available in \gretl and,
consequently, in \gretlpy. Note that all methods
outlined below are implemented as \gretl packages;
that is, they are not part of the core \lgretl library.


\subsection{Single Equation Models}
The \textbf{BayTool} package \cite[see][]{BayTool_CS}
for \gretl provides a collection of functions for Bayesian
estimation of single-equation models. The available
specifications range from traditional settings, such
as the linear model, to more advanced alternatives,
including the Bayesian LASSO and latent variable models.
Posterior distributions are obtained either analytically,
when closed-form solutions are available, or via Markov
chain Monte Carlo methods. In the latter case, diagnostic
tools for assessing simulation performance are also provided.
Below we present an example for the linear model; for more
advanced applications, the reader is referred to the package
documentation and \texttt{`packages/baytool.py'} script.
\begin{lstlisting}[style=pythonstylefoot]
import gretl

gretl..set('verbose', 'off')

try:
  bt = gretl.include('BayTool')
except FileNotFoundError:
  gretl.pkg('install', 'BayTool')
  bt = gretl.include('BayTool')
bt.show_functions()

gretl..set('seed', 1234567)

# Koop's textbook ("Bayesian Econometrics") example on house prices

d = gretl.get_data('AnglinGencay.gdt', frompkg='BayTool', quiet=True)
y = 'price'					    # dep. variable
X = 'const lot_size n_bedroom n_bathroom n_storeys' # covariates

prior = ~gretl.Bundle() # prior set-up
prior['type'] = 'indep' # independent Normal - IG
prior["beta_mean"] = ~gretl.Matrix([[0], [10], [5000], [10000], [10000]])
prior["beta_vcv"] = ~gretl.Matrix.diag([10000**2, 25, 2500**2, 5000**2, 5000**2])
prior['precision_mean'] = 4e-08
prior['precision_df'] = 5

opt = ~gretl.Bundle() # options
opt["forecast"] = ~gretl.Matrix([1, 5000, 2, 2, 1]) # matrix of regressors for prediction
gretl..set('stopwatch')
out = gretl.BT_lm(y=y, X=X, prior=prior, opt=opt)
print(f"Elapsed time in sec:: {gretl.get_accessor('$stopwatch'):.2f} sec.")
\end{lstlisting}\index{pkg()}\index{include()}\index{get\_data()}\index{set()}\index{Bundle()}\index{show\_functions()}%
\index{BT\_lm()}


\subsection{Bayesian Model Averaging}\label{sec.bma}
Bayesian Model Averaging (BMA) is a sophisticated
model-building strategy that accounts for model
uncertainty when drawing conclusions about estimated parameters.
It is an effective tool for identifying the most probable
models and obtaining estimates of their posterior
characteristics. For more information, please refer to
\cite{Steel2020}. In \gretl, several packages
support this type of analysis (in historical order):
\begin{description}
	\item[\textbf{BMA}] The package by \cite{BMA_JSS}
		implements the BMA procedure for linear models
		in an extremely numerically efficient manner.
	\item[\textbf{ParMA}] The package by \cite{ParMA_JSS}
		implements BMA for generalized linear models,
		parallelized via Message Passing Interface (MPI).
	\item[\textbf{BACE}] The package by \cite{BACE_JSS}
		implements Bayesian Averaging of Classical Estimates
		(BACE) for a wide class of single-equation models%
		\footnote{These are: logit and probit models, ordered
			logit and probit models, multinomial logistic
			regression, Poisson regression, the Tobit model,
			interval regression, and linear regression.}.
\end{description}
Below are snippets for all three packages mentioned above.

\paragraph{BMA}
This snippet replicates a well-known GDP growth factors modeling
study \cite[see][for details]{FernandezLeySteel2001_JoAE,
	FernandezLeySteel2001_JoE}.
Note that the whole procedure takes approximately 25 seconds
on machine powered by AMD Ryzen AI Pro 9 HX with 32~GB~RAM
(Debian GNU/Linux testing/unstable). For more advanced
applications, the reader is referred to the package
documentation and \texttt{`packages/bma.py'} script.
\begin{lstlisting}[style=pythonstylefoot]
import gretl

try:
  gretl.include('BMA')
except FileNotFoundError:
  gretl.pkg('install', 'BMA')
  gretl.include('BMA')

d = gretl.get_data('FLS_41t72', frompkg='BMA')
Factors = list(range(2, 43))

OPTS = ~gretl.Bundle()
OPTS['Nrep'] = 3000000
OPTS['burn'] = 33
OPTS['Nrank'] = 20
OPTS['do_joint'] = 'myq'

gretl..set('seed', 1000000)
gretl..set('stopwatch')
RES = gretl.BMA(Y='GDP_growth', X_list=Factors, Options=OPTS)
print(f"Total execution time: {gretl.get_accessor('$stopwatch'):.2f} sec.")
\end{lstlisting}\index{pkg()}\index{include()}\index{get\_data()}\index{set()}\index{Bundle()}\index{show\_functions()}%
\index{BMA()}

\paragraph{ParMA} The sample script contains a binary
model example of married women's labor participation.
The dataset comes from \cite{mroz87}. We set up a probit
model using as covariates the woman's socioeconomic
characteristics (\textit{WA, WE, AX, MTR}), her husband's
(\textit{HA, HE, HW}), as well as some household indicators
(\textit{KL6, CIT}) and county-level unemployment (\textit{UN}).
For more advanced applications, the reader is referred
to the package documentation. Note that the entire procedure
takes approximately 10 seconds on a machine powered by an AMD Ryzen
AI Pro 9 HX with 32~GB RAM (Debian GNU/Linux testing/unstable).
This is because, at present, \gretlpy does not
utilize \textbf{ParMA}'s capability for parallelization
via MPI.
\begin{lstlisting}[style=pythonstylefoot]
import gretl

gretl..set('verbose', 'off')

try:
  bv = gretl.include('ParMA')
except FileNotFoundError:
  gretl.pkg('install', 'ParMA')
  bv = gretl.include('ParMA')
bv.show_functions()

d = gretl.get_data('mroz87.gdt', quiet=True)
X = "KL6 WA WE HA HE HW MTR UN CIT AX"

modeltype = 'probit'
n_iter = 32 * 1024    # drawings after burn-in
burn_in = 2048        # burn-in

options = ~gretl.Bundle()
options["seed"] = 1_234_567

# use MPI if available
if gretl.about()['sysinfo']['mpi']:
  options['mpi'] = gretl.about()['sysinfo']['ncores']
else:
  options['mpi'] = 1

gretl..set('stopwatch')
b = gretl.bma_glm(y='LFP', X=X, glm_type=modeltype, ndraw=n_iter, burn=burn_in, parms=options)
print(f"Total execution time: {gretl.get_accessor('$stopwatch'):.2f} sec.")
\end{lstlisting}\index{pkg()}\index{include()}\index{get\_data()}\index{set()}\index{Bundle()}\index{show\_functions()}%
\index{bma\_glm()}

\paragraph{BACE} The sample script contains a ordered
probit model example applied to the so-called \textit{NELS}
dataset used in \cite{HillGriffithsLim_principles_2017},
which concerns a longitudinal study on eight-grade students
in USA\footnote{This dataset is available at
	\url{http://www.principlesofeconometrics.com/poe5/poe5data.html}.
	It is also available for \gretl, thanks to the work of Lee Adkins:
	\url{http://www.learneconometrics.com/gretl/index.html}.}.
\begin{lstlisting}[style=pythonstylefoot]
import gretl

try:
  bc = gretl.include('BACE')
except FileNotFoundError:
  gretl.pkg('install', 'BACE')
  bc = gretl.include('BACE')
bc.show_functions()

d = gretl.get_data('nels.gdt', frompkg='BACE', quiet=True)
dep = 'psechoice'
X = list(range(2, 15))

gretl..set('seed', 1000000)
gretl..set('stopwatch')
res = gretl.BACE(Y=dep, X_list=X, Options=~gretl.Bundle(model_type="probit"))
print(f"Total execution time: {gretl.get_accessor('$stopwatch'):.2f} sec.")
\end{lstlisting}\index{pkg()}\index{include()}\index{get\_data()}\index{set()}%
\index{Bundle()}\index{show\_functions()}\index{BACE()}


\subsection{Bayesian Vector Autoregression}\label{sec.bvar}
Bayesian Vector Autoregression (BVAR) has become a standard
paradigm in modern macroeconometric modeling. The \gretl
\textbf{BVAR} package \cite[see][]{BVAR_in_gretl_CS}
provides a comprehensive set of tools for conducting Bayesian
VAR analyses. Below is a sample script for the package; for
more advanced and detailed examples, the reader is referred
to the package documentation and the \texttt{packages/bvar.py} script.
\begin{lstlisting}[style=pythonstylefoot]
import gretl

gretl..set('verbose', 'off')

try:
  bv = gretl.include('BVAR')
except FileNotFoundError:
  gretl.pkg('install', 'BVAR')
  bv = gretl.include('BVAR')
bv.show_functions()

d = gretl.get_data('koopkoro.gdt', frompkg='BVAR')
dep = [1, 2, 3]

# Step 1 - BVAR_setup
model = gretl.BVAR_setup(y=dep, lag=4, .type='conj')

# Step 2 - prior customization
OPT = ~gretl.Bundle()
OPT['p_mean'] = 0
gretl.BVAR_sigma_prior(mod=model, prior_type='AR')
gretl.BVAR_alpha_prior(mod=model, prior_type='Minn', prior_opt=OPT)

# Step 3 - posterior simulation
gretl..set('seed', 1234)
res = gretl.BVAR_posterior(mod=model, wat='all', opt=~gretl.Bundle(.iter=10000))
res..print(tree=True)
\end{lstlisting}\index{pkg()}\index{include()}\index{get\_data()}\index{set()}\index{Bundle()}\index{show\_functions()}%
\index{BVAR\_posterior()}\index{BVAR\_setup()}\index{BVAR\_sigma\_prior()}
